INDIE GAME FEEL – DAMAGE INDICATORS PACK
======================================

This pack contains pixel-art damage indicators and combat feedback assets
designed for 2D games.

All assets are delivered as PNG files with transparency (alpha channel)
and are ready to use in common game engines such as Unity, Godot,
GameMaker, and similar frameworks.

--------------------------------------------------
FOLDER CONTENTS
--------------------------------------------------

Hit_Explosions/
- Single-frame pixel-art explosion effects
- Designed for hit impacts and combat feedback
- Each PNG contains multiple variations arranged in a grid

Directional_Indicators/
- Arrow-based indicators showing incoming damage direction
- Useful for shooters, roguelikes, and action games

Damage_Numbers/
- Pixel-art number styles for damage, score, or stat feedback
- Multiple visual styles included

Warning_Pulses/
- Loopable warning and danger indicators
- Intended for low-health, hazard, or alert states

Status_Icons/
- HUD and status icons for alerts, debuffs, cooldowns, and UI states
- Suitable for both gameplay and prototyping

--------------------------------------------------
TECHNICAL DETAILS
--------------------------------------------------

- File format: PNG
- Transparency: Yes (alpha channel)
- Color space: sRGB
- Style: Pixel art / 8-bit inspired
- Animation: Single-frame assets (can be animated or looped by the user)
